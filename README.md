# Concerto-Multi-Version

> [!NOTE]
> [原项目](https://github.com/GregTaoo/Concerto)已支持 Forge / NeoForge, 故本仓库归档

移植 [GregTaoo/Concerto](https://github.com/GregTaoo/Concerto) 到 Forge / NeoForge.

| 开发版本    | 支持版本             | 备注                         |

| 1.17.1  | 1.17.1           | -                          |
| 1.18.2  | 1.18.2           | 自动加入服务器点歌功能会报错, 请手动加入服务器点歌 |
| 1.19.4  | 1.19.4           | -                          |
| 1.20.1  | 1.20.1           | -                          |
| 1.20.4  | 1.20.4           | -                          |
| 1.20.6  | 1.20.6           | -                          |
| 1.21.1  | 1.21 ~ 1.21.1    | -                          |
| 1.21.2  | 1.21.2           | -                          |

| 1.21.5  | 1.21.5           | -                          |
